4. WHOLE APPLICATIONS ARE NOT INTERCHANGEABLE FEATURES
Cadence Next16/React19.2/Firebase/billing/ML stack is an archived alternative,
not a replacement for the working Next15/React19.0/LiveKit tutor. Auth, cloud
sync, lesson packs, pronunciation and desktop/mobile services need separate
rights, credentials, build and behavior acceptance. Do not merge manifests.
Cadence mouth articulation illustration and avatar teacher lip sync have
different purposes; combining them as one pronunciation score would be wrong.
Talking Avatar owns its output audio; active RoomAudioRenderer already does.
A later adapter must choose one owner instead of running both audio paths.
